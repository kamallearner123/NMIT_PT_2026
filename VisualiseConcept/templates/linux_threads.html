1. Processes vs Threads: Shared vs Separate

A Process is an independent program execution. A Thread (LWP - Light Weight Process) is a unit of execution within a process.

Key Insight: Threads share the same address space. This makes communication fast (no IPC needed) but dangerous (race conditions!).
Resource Shared? Reasoning
Code (Text) ✅ Yes All threads execute from the same binary.
Data (Global) ✅ Yes Allows global variable sharing across threads.
Heap ✅ Yes Memory allocated via malloc() is shared.
Stack ❌ No Each thread needs its own function call history.
PC (Prog Counter) ❌ No Each thread is at a different line of code.
Registers ❌ No Each thread has its own temporary calculations.
