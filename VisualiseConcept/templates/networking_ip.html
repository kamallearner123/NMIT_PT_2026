The Network Layer

IP Addressing, Subnetting, and Global Packet Delivery.

1. IPv4 Addressing & Structure

An IP address is a 32-bit identifier for a host. It is divided into a Network ID and a Host ID using a Subnet Mask.

192.168.1
10

The Mask

A mask like 255.255.255.0 (or /24) tells the computer which bits belong to the network.

3. How Linux Routes Packets

The Routing Table is the kernel's roadmap. It tells the OS which interface (eth0, wlan0) to use for a destination.

kamal@linux:~$ route -n
Destination Gateway Genmask Iface
0.0.0.0 192.168.1.1 0.0.0.0 eth0
192.168.1.0 0.0.0.0 255.255.255.0 eth0

The destination 0.0.0.0 is the Default Gateway—where all internet-bound traffic goes.

4. Socket Programming: Fetching Host Info

C code to resolve a hostname to an IP address (DNS resolution in C).

#include <stdio.h>       // Standard I/O library for printing
#include <string.h>      // Library for string operations like strcpy
#include <sys/socket.h>  // Core socket library for network constants
#include <netdb.h>       // Library for network database operations (DNS)
#include <arpa/inet.h>   // Library for IP address conversion functions

int main() {
    // 1. Declare variables to hold host info
    struct hostent *he;      // Structure to store host database entry
    struct in_addr **addr_list; // List of IP addresses returned by DNS
    char *hostname = "google.com"; // Hostname we want to resolve

    // 2. Use gethostbyname() syscall to query DNS
    // This is the core function that communicates with the resolver
    if ((he = gethostbyname(hostname)) == NULL) {
        herror("gethostbyname"); // Print error if DNS lookup fails
        return 1;
    }

    // 3. Extract the list of IP addresses from the host entity
    addr_list = (struct in_addr **)he->h_addr_list;

    // 4. Loop through the address list and print the first one
    for(int i = 0; addr_list[i] != NULL; i++) {
        // inet_ntoa converts binary IP to readable "dotted" string
        printf("%s resolved to: %s\n", hostname, inet_ntoa(*addr_list[i]));
        break; // Just show the first IP for simplicity
    }

    return 0; // Return success to the OS
}
