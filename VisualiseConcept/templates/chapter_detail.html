Graph Theory Essentials

Graphs are versatile data structures used to represent relationships between objects. A graph $G = (V, E)$ consists of a set of Vertices (nodes) and Edges (connections).

Types of Graphs

  • Directed: Edges have a specific direction (A $\rightarrow$ B).
  • Undirected: Edges are bidirectional (A $\leftrightarrow$ B).
  • Weighted: Edges have associated values (costs, distances).
  • Cyclic/Acyclic: Whether the graph contains paths that return to the starting node.

Representations

  • Adjacency Matrix: A 2D array where adj[i][j] is 1 (or weight) if an edge exists. Space: $O(V^2)$.
  • Adjacency List: An array of lists where adj[i] contains neighbors of $i$. Space: $O(V + E)$.

🔥 Common Interview Patterns

1. Connectivity: Can we reach B from A? (Use BFS/DFS)
2. Shortest Path: Dijkstra (weights $\ge 0$), Bellman-Ford (negative weights).
3. Cycle Detection: DFS (back edges) or Kahn's Algorithm (topological sort).
4. MST: Prim's or Kruskal's for minimum cost connections.
5. Topological Sort: Ordering tasks with dependencies (Kahn's/DFS).
6. Island Problems: Finding connected components in a grid (DFS).
