03. Prompt Engineering Deep Dive

Mastering the art of communicating with LLMs to get precise, reliable, and high-quality outputs.

Prompting Strategies (Block Diagram)

1. Zero-Shot

Asking the AI a question without giving any examples.

User: Classify this text as Positive or Negative: "I love this product!"

AI: Positive.

2. Few-Shot

Providing a few examples before asking the actual question.

User:
"Terrible service" -> Negative
"Great food" -> Positive
"Okay experience" -> Neutral
"I enjoyed it" ->

AI: Positive.

3. Chain-of-Thought (CoT)

Forcing the AI to explain its reasoning step-by-step.

User: If I have 5 apples and eat 2, then buy 4 more, how many do I have? Think step-by-step.

AI: 1. Start with 5.
2. Eat 2, so 5-2=3.
3. Buy 4, so 3+4=7.
Answer is 7.

Code Example: System Prompts vs User Prompts


# When using the Chat API, we separate instructions (System) from the task (User).

messages = [
    {
        # The System prompt sets the behavior, rules, and persona.
        "role": "system", 
        "content": """You are an expert Python developer. 
Always reply with valid, runnable code only. 
Do not explain the code unless asked."""
    },
    {
        # The User prompt is the specific task or question.
        "role": "user", 
        "content": "Write a function to calculate the Fibonacci sequence."
    }
