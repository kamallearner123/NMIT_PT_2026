10. Capstone Projects

Showcase your mastery of Agentic AI by building a complete, production-ready system.

Project Ideas

Idea 1: Autonomous Research Assistant

An agent that takes a topic, searches the web, reads 5 articles, extracts key points, and writes a comprehensive markdown summary.

Tech Stack: Python, CrewAI, Tavily Search API, OpenAI.

Idea 2: Chat-with-your-Database

A UI where users can ask questions in plain English (e.g., "Show me top 5 customers this month") and the agent converts it to SQL, runs it, and explains the data.

Tech Stack: FastAPI, React, LangChain SQL Agent, PostgreSQL.

Idea 3: Customer Support RAG System

A chatbot loaded with company PDFs that can accurately answer user queries, cite sources, and escalate to a human if uncertain.

Tech Stack: LlamaIndex, Pinecone, Streamlit UI.

Idea 4: Local MCP Developer Tool

Build an MCP server that exposes your local filesystem and bash terminal to Claude Desktop to automate coding tasks.

Tech Stack: Node.js/Python, MCP SDK, Claude Desktop.
