Code Example: Running Local Models with Ollama

Using the official Ollama Python library to query a local model without API costs.


# pip install ollama
import ollama

# Assuming you have Ollama running locally and have downloaded 'llama3'
# e.g., in terminal: ollama run llama3

response = ollama.chat(model='llama3', messages=[
  {
    'role': 'user',
    'content': 'Why is the sky blue?',
  },
])

print(response['message']['content'])
