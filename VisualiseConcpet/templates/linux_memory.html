Memory Management

From C code malloc() to Kernel Page Tables.

0. Process Memory Layout (Segments)

When a program runs, it is organized into several segments. Here is how a C program maps to RAM:

Stack (Local Vars, gows ⬇)
Shared Libraries / Empty Space
Heap (malloc, grows ⬆)
BSS (Uninitialized Globals)
Data (Initialized Globals)
Text (Binary Code)
#include <stdlib.h>

int global_init = 10;        // [Data Segment]
int global_uninit;           // [BSS Segment]

int main() {
    int local_var = 5;       // [Stack Segment]
    static int s_var = 2;    // [Data Segment]
    
    // [Heap Segment]
    int *ptr = malloc(100); 
    
    // [Text Segment]
    printf("Hello World");   
    
    return 0;
}

1. Core Concepts

Virtual Memory

Each process thinks it has its own private, contiguous memory space. This is an illusion provided by the OS.

Paging

Physical RAM is divided into small chunks called Pages (usually 4KB). The OS maps Virtual pages to Physical pages.

Swapping

When RAM is full, the OS moves inactive pages to the disk (Swap Partition/File) to free up physical space.

3. C Example: Allocate & Free

#include <stdio.h>
#include <stdlib.h>

int main() {
    // 1. Requesting memory for 5 integers
    int *ptr = (int*)malloc(5 * sizeof(int));

    if (ptr == NULL) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    // 2. Using the memory
    for (int i = 0; i < 5; i++) {
        ptr[i] = i * 10;
        printf("Value at index %d: %d\n", i, ptr[i]);
    }

    // 3. FREEING the memory (Very important!)
    // This tells the OS/glibc that we are done.
    free(ptr);

    return 0;
}

What malloc does:

It reserves a block of bytes on the Heap. It returns a pointer to the first byte.

What free does:

It marks the block as "available" for future malloc calls. If you don't call it, you get a Memory Leak.

4. The Free List (Data Structure)

Internally, malloc keeps track of free memory blocks using a Linked List. Each node represents a "hole" in the heap.

Size: 512B
Next →
Size: 1024B
Next →
Size: 256B
NULL

Fragmentation

Over time, as blocks are allocated and freed, the "holes" get smaller and scattered. This is called External Fragmentation.

Coalescing

When two adjacent blocks are freed, the kernel merges them back into one large block to keep the list efficient.
