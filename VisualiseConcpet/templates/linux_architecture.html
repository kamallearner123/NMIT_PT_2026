Linux Architecture & Core Concepts

Understanding the layers that power the world's most versatile operating system.

1. The Layered Design

User Space (Applications)

Browser, Shell, Editors, Games

System Call Interface (SCI)
Kernel Space

Process Mgmt, Memory Mgmt, VFS, Network Stack

Hardware

CPU, RAM, Disk, NIC, GPU

Kernel Space

Runs in privileged mode. It has direct access to hardware and manages system resources for everyone.

User Space

Runs in restricted mode. Applications here must ask the kernel for permission to use hardware via System Calls.
