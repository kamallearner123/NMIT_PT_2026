What do they mean?

  • Read (r): Ability to see file contents or list directory files.
  • Write (w): Ability to modify file or add/remove files in directory.
  • Execute (x): Ability to run file as a program or enter directory.

Common Permissions

  • 777: Everyone can do everything (Dangerous!)
  • 755: Owner can do all, others can read/execute.
  • 644: Owner can read/write, others read-only.
  • 400: Only owner can read (Typical for SSH keys).
