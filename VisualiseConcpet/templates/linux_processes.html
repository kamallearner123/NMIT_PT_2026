Step 2: Scheduling & Registers

When the Scheduler picks this process to run:

  1. Context Switch: The OS loads the process's saved state into CPU registers.
  2. PC Role: The CPU looks at the Program Counter to know which line of code to execute next from the Text segment.
  3. SP Role: The Stack Pointer keeps track of the current function call's variables and return address.

How data is copied: The CPU doesn't fetch 1 byte at a time. It pulls Cache Lines (usually 64 bytes). If the code needs x, it pulls the whole block around x into L2, then L1. This is why Spatial Locality (looping through arrays) is so fast!

Essential Process Commands

Command Description Example
ps aux List all running processes with user info. ps aux | grep python
top / htop Real-time system monitor and process viewer. htop
kill / pkill Send signals to processes (Stop/Terminate). kill -9 1234 or pkill chrome
nice / renice Set or change process priority (Niceness). nice -n 10 ./script.sh
strace Trace system calls and signals of a process. strace ls
lsof List open files (and the processes that opened them). lsof -i :8000
pstree Display processes as a tree (Visual hierarchy). pstree -p
jobs / bg / fg Manage background and foreground tasks. fg %1
