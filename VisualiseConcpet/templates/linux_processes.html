2. Process State Machine (5-State Model)

Beyond creation, a process lives in one of these five states. Here is how they interact:

1. New

Process is created.

Example: You type firefox. Linux creates a new process.
NEW → READY
Reason: OS allocates memory, PID, and resources.

2. Ready

Ready to run, but waiting for CPU.

Example: Many apps are open, CPU can execute only one at a time.
READY → RUNNING
Reason: CPU scheduler selects it.

3. Running

Currently executing on CPU.

Example: Your Python program is executing instructions.
RUNNING → READY (Timeout)
RUNNING → WAITING (I/O)

4. Waiting / Blocked

Waiting for an event (I/O).

Examples: Disk read, Keyboard input, Network response.
WAITING → READY
Reason: I/O completed.

5. Terminated

Process finishes execution.

Example: Program ends.
RUNNING → TERMINATED
Reason: Exit signal or Completion.
