Encoder-Decoder Architecture

While models like BERT use only Encoders (for understanding) and GPT uses only Decoders (for generating), the original Transformer used both (e.g., for translation). Let's visualize how they interact!

Cross-Attention

In the Decoder, the Queries (Q) come from the previous decoder layer (the words generated so far), but the Keys (K) and Values (V) come from the Encoder's output! This allows the Decoder to "look back" at the original French sentence while generating the English translation.

import torch.nn as nn class TransformerBlock(nn.Module): def __init__(self, embed_size, heads, dropout, forward_expansion): super().__init__() self.attention = SelfAttention(embed_size, heads) self.norm1 = nn.LayerNorm(embed_size) self.norm2 = nn.LayerNorm(embed_size) self.feed_forward = nn.Sequential( nn.Linear(embed_size, forward_expansion * embed_size), nn.ReLU(), nn.Linear(forward_expansion * embed_size, embed_size) ) self.dropout = nn.Dropout(dropout) def forward(self, value, key, query, mask): # Multi-head attention attention = self.attention(value, key, query, mask) # Add & Norm (Skip connection) x = self.dropout(self.norm1(attention + query)) # Feed Forward forward = self.feed_forward(x) # Add & Norm (Skip connection) out = self.dropout(self.norm2(forward + x)) return out
